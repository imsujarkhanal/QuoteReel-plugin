# QuoteReel

QuoteReel is a lightweight Elementor widget plugin that helps you showcase customer testimonials in a clean, modern carousel layout. It is built for WordPress websites using Elementor and gives you an easy way to display reviews, star ratings, client names, locations, and profile images without writing any code.

The plugin adds a custom **Testimonial Carousel** widget to Elementor. From the Elementor editor, you can add multiple testimonial items, choose how many slides appear at once, control spacing, enable looping, turn autoplay on or off, and customize navigation and pagination styles.

QuoteReel uses Swiper for smooth carousel behavior and includes responsive styling so testimonials look polished on desktop, tablet, and mobile devices. It is ideal for portfolios, business websites, service pages, landing pages, and any site that needs to build trust through real client feedback.

## Key Features

- Custom Elementor testimonial carousel widget
- Add unlimited testimonial items
- Star rating support
- Client name, location, review text, and image fields
- Adjustable slides per view and slides per scroll
- Loop, autoplay, pause-on-hover, and center mode options
- Multiple navigation styles: arrows, text, or icons
- Pagination options including bullets, numbers, fraction, and progress bar
- Responsive layout for mobile and desktop
- Simple, lightweight CSS and JavaScript

## Short Description

QuoteReel is a custom Elementor testimonial carousel plugin for WordPress. It lets you display client reviews, ratings, names, locations, and profile images in a smooth responsive slider with customizable navigation, pagination, autoplay, spacing, and layout options.
